brand

## Purpose

Russian developer portfolio for clients commissioning web products, Telegram mini apps, bots and business systems. Show engineering through four substantial interactive case studies, then direct enquiries to https://t.me/landlancer.

## Direction

Confident, precise, tactile. White and vivid blue, clear hierarchy, ambitious interface compositions, restrained motion. No old landing-page gallery, laptop hero, inflated metrics, invented results, or internal repository names in public copy. Each case is an interactive article in the same visual identity, with alternating text and demos. Loyalty API and 12K Mini App form one unfinished case.

## Accessibility

Keyboard controls, readable contrast, semantic navigation, reduced motion, responsive layouts from 320px.

## Acceptance

Four case links, four independent indexable pages, local demo interactions, accurate scope from source files, visible in-development status, working Telegram links. All demo balances, pets and rewards are fictional; no production calls.
