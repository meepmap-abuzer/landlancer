# Lunar garden

Authored Three.js scene for Lancer Agency: procedural terrain, eroded basalt rocks, gravel and instanced curved silver grass. Grass wind and cursor deformation run in the vertex shader. Original geometry and procedural texture; no external model or image license required. Three.js MIT license is in THREE-LICENSE.txt.

Desktop: up to 34,000 instanced blades; mobile: 14,000. Rendering is suspended outside the viewport, in hidden tabs, with reduced motion or via the shared pause control.
