# Interactive landscape attribution

Terrain displacement adapted from Interactive Landscape by André Mattos / Codrops (2018): https://github.com/ma77os/InteractiveLandscape . Custom materials, camera, mesh butterflies, interaction and lifecycle were added for Lancer Agency. This is an integrated adaptation, not redistribution of the original resource as-is.
