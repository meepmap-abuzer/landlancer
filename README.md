# LandLancer — новая версия портфолио

Главная и четыре самостоятельные страницы кейсов в общей сине-белой палитре. Статический сайт без runtime-зависимостей и внешних запросов за шрифтами или изображениями.

## Запуск

Требуется Node.js 22 или новее. Установка npm-пакетов не нужна.

```sh
npm run build
npm run dev
```

Локальный адрес: http://127.0.0.1:4173

## Файлы

- `src/build.mjs` — тексты, данные кейсов и генератор HTML.
- `src/screenshots.mjs` — галереи настоящих экранов и подписи к ним.
- `site.css` — общий дизайн и мобильная вёрстка.
- `site.js` — меню, рулетка, фильтры каталога, сценарий лояльности и переворот карты.
- `assets/` — используемые иллюстрации.
- `cases/` — страницы кейсов. Прежние адреса трёх проектов сохранены.

Внутренние названия проектов не используются в видимых заголовках. Loyalty API и 12K Mini App объединены в один кейс с отметкой «В разработке».

## Демонстрации

Демо переоформлены для портфолио по сценариям исходных проектов. Они работают только в браузере: не совершают платежей, не отправляют запросы к рабочим API, не создают заказы и не используют данные клиентов. QR — иллюстрация, а не действующий код. Карта животных схематичная. Иллюстрации собак взяты из исходного проекта. Награды нарисованы для портфолио.

Факты проверены по README игровой платформы, Product и компоненту ScenarioSection сервиса животных, Product и компоненту RouletteView программы лояльности, Product обоих проектов розничной системы и компоненту LoyaltyCard.

Скриншоты игрового приложения взяты из [публичного репозитория проекта](https://github.com/meepmap-abuzer/telegram-gaming-platform/tree/main/screenshots). Остальные — из сохранённых материалов соответствующих проектов. Экран кабинета бизнеса показывает настоящий раздел отчётов на тестовых данных. Снимки сохранены в исходных цветах внутри общего сине-белого оформления. Увеличение доступно по нажатию, переключение — кнопками или стрелками клавиатуры, закрытие — кнопкой или Escape.

## Публикация

Для выгрузки используйте папку `../landlancer-ready` или архив `../landlancer-ready.zip`. Они содержат только новую главную, четыре кейса и необходимые ресурсы. Старые демонстрационные лендинги туда не входят. Содержимое нужно размещать в корне домена: сайт использует абсолютные пути от `/`.

`CNAME` сохраняет landlancer.ru. Подходит обычный статический хостинг или GitHub Pages. Текущая версия не отправлялась в удалённый репозиторий и не публиковалась на рабочем домене.

## Проверено

- Сборка и синтаксис JavaScript.
- Все четыре интерактивных сценария в браузере.
- Блокировка повторного запуска рулетки во время анимации.
- Мобильное меню, переходы между кейсами и ссылки на Telegram.
- Главная на 320 и 390 px, кейсы на 390 px, настольная версия.
- Наличие изображений и внутренних ссылок.
- Уважение prefers-reduced-motion предусмотрено в CSS и логике рулетки.
