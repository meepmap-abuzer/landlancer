# Lancer Agency

Статический сайт агентства, шесть направлений услуг и четыре кейса: Gift Roulette, Maverick, TailCare и 12К. Оформление соединяет изображения, матовое стекло и оливковый фон. На страницах проектов доступны локальные интерактивные демо.

## Сборка и запуск

Node.js 22.15 или новее:

```sh
npm ci
npm run build
npm run dev
```

Локальный адрес: http://127.0.0.1:4173/. `npm run check` проверяет синтаксис, `npm test` запускает восемь тестов логики демо и оптики стекла.

- `src/agency-home.mjs`, `src/agency-cases.mjs`, `src/agency-shared.mjs` — шаблоны страниц.
- `src/build-agency.mjs` — генератор HTML.
- `lancer.css`, `service-editorial.css`, `case-editorial.css` — основа компонентов; `frost.css` загружается последним и задаёт текущую визуальную систему.
- `studio-world.mjs`, `disclosures.mjs` — анимации появления, вкладки и плавное раскрытие блоков; `agency.js` — поведение кейсов.
- `src/demos/` — Vue-компоненты продуктов; `demos/` — готовые чанки для публикации.
- `DEMOS.md` — происхождение компонентов, адаптации и проверки.
- `ASSET_PROVENANCE.md` — источники визуальных материалов.

Демо работают в браузере без авторизации, платежей и обращений к рабочим API продуктов. QR содержит демонстрационное значение. Шрифты, изображения и библиотеки размещены вместе с сайтом.

## GitHub Pages

Сайт: https://landlancer.ru. Репозиторий `meepmap-abuzer/landlancer` публикует корень ветки `main`. Файл `CNAME` сохраняет домен, `.nojekyll` позволяет отдавать все готовые JS-чанки. После изменений нужно собрать сайт и сохранить исходники вместе с готовыми HTML и `demos/`.

`node src/package.mjs` обновляет статическую копию в `../landlancer-ready`. Для публикации из ветки npm на стороне GitHub не требуется: браузер получает уже собранные файлы. Пути ресурсов начинаются с `/`, сайт рассчитан на корень домена.

Для текущей версии проверены восемь тестов логики демо и оптики, семь проверок SEO и публичных маршрутов. Главная, каталог, услуги сайтов и AI, а также кейс Maverick просмотрены в Chromium на десктопе и телефоне. Safari и Firefox отдельно не проверялись.

Предыдущая опубликованная версия: `437ebb2`. Для отката восстановите её дерево новым коммитом в `main` и дождитесь GitHub Pages deployment, не переписывая историю. Перед восстановлением убедитесь, что новые изменения других авторов не будут потеряны.
