# Lancer Agency

Статический сайт агентства, шесть направлений услуг и четыре кейса: Gift Roulette, Maverick, TailCare и 12К. Текущий стиль — чёрный, серый и белый, матовые поверхности без внешних рамок и авторские схемы интерфейсов. Обложки работ — сгенерированные визуализации устройств по исходным скриншотам проектов; на страницах услуг сохранены настоящие снимки интерфейсов. На страницах проектов доступны локальные интерактивные демо.

## Сборка и запуск

Node.js 22.15 или новее:

```sh
npm ci
npm run build
npm run dev
```

Локальный адрес: http://127.0.0.1:4173/. `npm run check` проверяет синтаксис, `npm test` запускает восемь тестов логики демо и оптики стекла.

- `src/agency-home.mjs`, `src/agency-cases.mjs`, `src/agency-shared.mjs` — шаблоны страниц.
- `src/build-agency.mjs` — генератор HTML.
- `lancer.css`, `service-editorial.css`, `case-editorial.css` — основа компонентов; `frost.css` загружается последним и задаёт текущую визуальную систему.
- `studio-world.mjs`, `disclosures.mjs` — анимации появления, вкладки и плавное раскрытие блоков; `agency.js` — поведение кейсов.
- `src/digital-visuals.mjs`, `src/project-cover.mjs` — авторские SVG-схемы и обложки работ; циклы декоративной анимации останавливаются вне экрана, в скрытой вкладке и при reduced motion.
- `src/demos/` — Vue-компоненты продуктов; `demos/` — готовые чанки для публикации.
- `DEMOS.md` — происхождение компонентов, адаптации и проверки.
- `ASSET_PROVENANCE.md` — источники визуальных материалов.

Демо работают в браузере без авторизации, платежей и обращений к рабочим API продуктов. QR содержит демонстрационное значение. Шрифты, изображения и библиотеки размещены вместе с сайтом.

## GitHub Pages

Сайт: https://landlancer.ru. Репозиторий `meepmap-abuzer/landlancer` публикует корень ветки `main`. Файл `CNAME` сохраняет домен, `.nojekyll` позволяет отдавать все готовые JS-чанки. После изменений нужно собрать сайт и сохранить исходники вместе с готовыми HTML и `demos/`.

`node src/package.mjs` обновляет статическую копию в `../landlancer-ready`. Для публикации из ветки npm на стороне GitHub не требуется: браузер получает уже собранные файлы. Пути ресурсов начинаются с `/`, сайт рассчитан на корень домена.

После обновления обложек прошли финальная сборка и семь проверок SEO, ссылок, схем, загрузки и цен. Восемь тестов логики демо и оптики ранее прошли для неизменённой логики. Главная, каталог, услуги сайтов и AI, а также кейс 12К просмотрены в Chromium на десктопе и телефоне; отдельно проверены четыре новые обложки и их размещение. Материалы локальной проверки находятся в `.impeccable/review/mono-runtime.md`, независимой проверки — в `mono-finish-review.md` и `mono-fix-verdict.md`. Safari и Firefox отдельно не проверялись.

Предыдущая опубликованная версия: `bb4e14e`. Для отката восстановите её дерево новым коммитом в `main` и дождитесь GitHub Pages deployment, не переписывая историю. Перед восстановлением убедитесь, что новые изменения других авторов не будут потеряны.
